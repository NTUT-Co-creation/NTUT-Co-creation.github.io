サイトの編集について

産学連携プロジェクトのウェブサイトは、このフォルダから編集できます。

1編集をはじめる

このフォルダにある editor.html をダブルクリックしてください。 編集ツールが開きます。

Google Chrome または Microsoft Edge で開いてください。 Windows の方は Edge がそのまま使えます。Mac の Safari では保存ができないため、 Chrome か Edge をお使いください。

2フォルダを選ぶ

右上の「編集をはじめる」を押すと、フォルダを選ぶ画面が出ます。 産学連携サイト編集 という名前のフォルダ（このファイルが入っているフォルダです）を選んで 「開く」を押してください。

続けて「編集を許可しますか？」と聞かれたら「許可」を押します。

この操作が必要なのは最初の1回だけです。次からは editor.html を開くだけで、 すぐ編集画面になります。

フォルダが見つからないときは、ツールの画面に「フォルダが見つからないとき」という案内があります。 Windows・Mac それぞれの探し方が出ますのでご覧ください。

3編集して保存する

左の一覧から事例を選ぶと、次のものを直せます。

  • 文章（概要、担当者のコメント、期間、教員名など）
  • 写真の差し替え・追加・削除
  • 関連サイトのリンク

右側に実際の表示が出ますので、確認しながら進めてください。 よければ「保存する」を押します。新しい事例を作ることもできます。

写真は JPEG か PNG をお使いください。カメラやスマホの写真ならそのままで大丈夫です。 大きさは自動で調整されます。印刷用の TIFF 形式は扱えません。

4公開されるまで

保存した内容は、すぐには公開されません。 渡辺が内容を確認したうえで、ウェブサイトに反映します。

操作を間違えても大丈夫です。公開中のサイトが勝手に変わることはありませんし、 元の状態にはいつでも戻せます。安心してお試しください。
